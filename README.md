# Altar de Día de Muertos Interactivo

Proyecto final de **Computación Gráfica e Interacción Humano-Computadora**  
Facultad de Ingeniería, UNAM — Semestre 2027-1

## Descripción

Sistema gráfico interactivo en 3D que representa un **altar tradicional de Día de Muertos** mexicano. El proyecto aplica el pipeline gráfico completo: conceptualización, modelado geométrico, análisis de color, texturizado, iluminación, sombreado, animación, simulación, interacción y renderizado.

El altar está compuesto por **3 niveles** con ofrendas típicas: velas, pan de muerto, frutas, flores de cempasúchil, calaveritas de azúcar, fotografías, cruz e incensario. Cada elemento fue modelado con primitivas y colores planos, e integra iluminación en tiempo real con técnicas Phong y Fresnel.

## Características técnicas

- **Modelado:** 3 niveles jerárquicos con primitivas (cubos, cilindros, conos, esferas, toros)
- **Iluminación:** Phong (materiales opacos) + Fresnel (materiales translúcidos/metálicos)
- **Texturizado:** Skybox con cube mapping + texturas en modelos propios
- **Animaciones:** Llamas de velas, papel picado, humo de incienso, calaca bailando
- **Interacción:** 8 animaciones controladas por input del usuario
- **Tecnología:** OpenGL 3+ / GLSL / Blender para modelado

## Temática

**México y su cultura** — Representación de una de las tradiciones más emblemáticas del país: el Día de Muertos.
